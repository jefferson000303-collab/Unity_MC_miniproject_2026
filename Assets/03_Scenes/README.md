# 🛠️ [1인가구 페르소나 컨피규레이터 구현 프로젝트]  (Persona Configurator)

> 유니티(Unity) 기반의 1인칭 시점 3D 공간 탐색 및 가구/환경 상호작용 컨피규레이터 프로그램입니다.

---

## 📌 주요 기능 (Features)
* **[기능 1]** - WASD / 방향키를 이용한 3D 공간 이동
* **[기능 2]** - UI를 통해 가구배치 및 분위기를 즉시 변경하고 미니맵으로 확인할 수 있음
* **[기능 3]** - 가구와 상호작용(E)하거나 자리에서 바로 제외(Q)할 수 있음

```bash
### 실행 방법 (Usage)

```
| 구분 | 키 (Key) | 동작 설명 |
| :--- | :--- | :--- |
| **이동** | `W`, `A`, `S`, `D` | 앞, 뒤, 좌, 우 이동 |
| **시점** | `Mouse Move` | 360도 시점 회전 (상하/좌우) |
| **메뉴 열기** | `ESC` | 메뉴 열림 |
| **상호작용** | `E` | 대상 오브젝트 상호작용 (`IInteractable`) |
| **메시 토글** | `Q` | 대상 오브젝트 메쉬 렌더러 켜기/끄기 (`MeshToggle`) |

## ⚙️ 컨피규레이터 UI 사용방법 (Configuration)

컨피규레이터 자체를 설정하는 방법을 적어줍니다. 

* **[기능 1]** - 페르소나 선택 / 해당 페르소나로 즉시 변경
* **[기능 2]** - 믹스 페르소나 / 구역별로 원하는 페르소나로 변경가능
* **[기능 3]** - VR모드 / 설정한 형태의 방 내부를 직접 확인가능
* **[기능 4]** - 일조량 변경 / 슬라이더 바를 통해 일조량을 변경 할 수 있음
* **[기능 5]** - 견적확인 / 페르소나를 변경 할 때 예산이 즉시 반영되어 확인 할 수 있음
